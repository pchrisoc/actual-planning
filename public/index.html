How to enable direct apply on your server

Edit /home/pchrisoc/financial-planner/.env on the Docker VM and set ACTUAL_WRITE_ENABLED=true. Then run:

cd /home/pchrisoc/financial-planner
docker compose up -d --no-deps planner

Refresh this page and populate a fresh preview. Enabling does not apply a draft automatically. All selected months must be readable, and applying still requires your review and confirmation. Local snapshot mode always stays read-only.

Each savings goal appears here automatically. Choose an existing Actual category for its contributions, or Do not populate to keep it as a forecast. If you need a new category, create it in Actual, then refresh categories here.

Months to populate

When the start date is after the 1st, existing funded categories in that month stay unchanged. Later months use the forecast. Uncheck only to deliberately replace the whole start-month allocation.

401(k) payroll deductions and employer contributions are not assigned to spending categories. Only selected IRA, loan and savings goal contributions are populated. Forecast interest is not assigned to categories. Other categories are left alone.
